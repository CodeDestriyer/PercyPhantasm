# Кристалл Раннер — 3D игра в браузере

Простая 3D-аркада на **Three.js** + React + Vite. Катаешь шар по арене,
собираешь светящиеся кристаллы за 60 секунд и стараешься не свалиться с края.

## Как запустить

```bash
npm install
npm run dev
```

Открой ссылку, которую покажет терминал (обычно http://localhost:5173).

## Управление

- **WASD** или **стрелки** — двигать шар
- На телефоне — **тяни пальцем** по экрану
- Собирай кристаллы (⬥), следи за таймером (⏱), бей рекорд (★)

## Сборка

```bash
npm run build     # собрать в папку dist/
npm run preview   # посмотреть собранную версию
```

## Где что лежит

- `src/Game.tsx` — вся игра (сцена, физика шара, кристаллы, счёт)
- `src/index.css` — оформление меню и HUD
- `src/App.tsx` — точка входа, просто рендерит игру
